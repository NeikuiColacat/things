# Python Packages For DOCX Work

- `python-docx`: create/edit paragraphs, runs, tables, images, sections, styles.
- `docxtpl`: fill Jinja-like placeholders inside prepared `.docx` templates.
- `docxcompose`: merge `.docx` documents while preserving section-level formatting.
- `docx2python`: extract document text, tables, headers, footers, and footnotes.
- `mammoth`: convert `.docx` to clean HTML/Markdown-like content for inspection.
- `lxml`: inspect or patch OOXML when high-level libraries lack an API.
- `pypandoc`: convert Markdown/HTML to `.docx` when system `pandoc` is available.
