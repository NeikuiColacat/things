# 桂电 Word 排版避坑清单

这些规则来自真实本科毕设 Word 排版反复修正经验，已去除具体项目内容，可作为通用检查表。

## 总原则

- 不要只看 DOCX 结构就说排版完成；必须导出 PDF 后逐页检查。
- 学校模板优先于 Agent 自己设计的样式。
- `thesis.md` 或 Markdown 适合管正文和版本差异，最终封面、声明、目录、页眉页码、图表题和参考文献仍要以 Word/PDF 渲染结果为准。
- 小修优先补丁当前终稿 DOCX；不要因为改几个字就全量重建 Word，重建会重写封面、目录、分节、页眉页脚和分页。
- 不要创建一堆 `修正版`、`最终版2`、`日期版`；用 Git 或明确的交付目录管理版本。

## 封面和声明

常见问题：

- 封面被挤成两页。
- 封面或声明页残留页眉。
- `题目：` 被挤成上下两行。
- 日期单独跑到第二页。
- 手工封面直接复制进新 DOCX 后行距、列宽、页眉页脚全变。

建议：

- 封面和声明优先使用学校官方附件或已经人工校验过的最终 DOCX 页面。
- 若题目较长，优先调封面表格列宽、个人信息表行高和空白段落，确保封面仍为一页。
- 声明页不要随手改写学校原文；签名和日期要求按学院通知人工处理。
- 前置页和正文之间要正确分节；封面、声明页通常不应显示正文页眉。

## 目录

常见问题：

- PDF 中出现“目录将在 Word/WPS 中更新后显示”。
- 目录页码列不齐。
- 更新目录后缩进、点引导线、页码制表位跑偏。
- 三级标题遗漏。
- 为了压成一页把目录改成静态手写文本。

建议：

- 使用真实 Word 自动目录域，不要手写静态目录。
- 目录可以超过一页，不能为了压缩页数破坏样式。
- 目录一般列到三级标题，不列摘要和英文摘要。
- 右侧页码对齐要检查实际 Word/WPS 更新后的效果；只改当前段落不够时，需要同步检查 TOC 样式。
- 每次调整章节、图表或分页后都要重新更新目录并导出 PDF。

## 页眉页码

常见问题：

- 封面、声明页误带页眉。
- 正文页码没有从正文首页重新开始。
- LibreOffice 导出的总页数和本地 Word/WPS 导出的最终页数不同。
- 全量重建后把人工校过的页眉总页数覆盖掉。

建议：

- 明确区分前置页、摘要页、目录页、正文页的分节和页眉策略。
- 正文页码通常从正文第一章开始重新计数。
- 最终总页数以提交环境使用的 Word/WPS 导出 PDF 为准，不要盲信 LibreOffice 自动页数字段。
- 调整分页控制后必须重新核对目录页码、正文页眉和末页页码。

## 字体和加粗

常见问题：

- 把“黑体”理解成额外 `bold=True`，导致标题、目录项、图表题过粗。
- 中英文混排时手工插入大量半角空格，文本层不干净。
- 使用不可见字符压缩视觉间距，后续检查和复制文本都很麻烦。

建议：

- 学校要求“黑体/楷体/宋体”时，优先设置字体族和字号；只有明确要求加粗时才额外加粗。
- 中英文之间的视觉间距可交给 Word/WPS 渲染处理，检查重点是真实文本层是否多了无意义空格。
- 英文摘要标题、`Key words`、表头等是否加粗按模板检查，不要一刀切。

## 公式

常见问题：

- 公式上方空白明显大于下方空白。
- 公式编号右括号换行。
- 公式被 PDF 导出截断。
- 用 LibreOffice 或在线工具导出时数学符号显示异常。

建议：

- 公式编号右对齐，并设置编号单元格不换行。
- 公式段前段后不要过大；导出 PDF 后检查上下间距。
- 正文引用公式时保持统一写法，例如 `公式3.1`。
- 最终交付 PDF 最好用学生本机 Word/WPS 导出并逐页检查公式。

## 图表和题注

常见问题：

- 表题放在表格下方，图题放在图片上方。
- 图题或表题与图表分页拆开。
- 图号表号和标题之间没有空格，导致转换脚本识别失败。
- 图片变成浮动锚点，覆盖正文。

建议：

- 表题置于表格上方居中；图题置于图片下方居中。
- 图号/表号和题名之间留一个空格，例如 `表3.2 测试用例`、`图4.1 系统架构`。
- 图片尽量使用 inline 布局并居中，避免浮动锚点覆盖文字。
- 图表前后使用“与下段同页”“段中不分页”等控制时要谨慎，调整后必须重新导出 PDF。

## 表格

常见问题：

- 表格超出版心。
- 方法名或指标名过长，导致列宽拥挤。
- 跨页表格表头丢失。
- 强制整表不分页，导致上一页留下大块空白。

建议：

- 小表可以尽量整表不分页；大表不要强行整表不分页。
- 长标签可在表中缩短，完整含义放在表前后正文解释。
- 宽表优先减少列、缩短列名或拆成两个表，不要单纯缩小字体到不可读。
- 表格行可以设置“行内不跨页”，但仍要检查 PDF 中是否产生大空白。

## 参考文献

常见问题：

- 参考文献标题位置和字体与学校要求不一致。
- 英文参考文献被保留蓝色超链接和下划线。
- 文献续行没有与首行正文对齐。
- 技术网页资料被错误标成标准或报告。

建议：

- `参考文献` 通常另起一页，按学校要求设置字体、字号和对齐方式。
- 参考文献条目应去掉蓝色超链接样式，保留必要 URL/访问日期即可。
- 序号用中括号，续行与首行正文起点对齐。
- 网页和官方文档通常按电子文献 `[EB/OL]` 处理，除非来源本身是正式标准或报告。

## 合并 DOCX

常见问题：

- `docxcompose` 合并后文件能打开，但封面、标题页或前置页分页被压缩。
- 合并后页眉页脚、分节或页面边距被意外继承。

建议：

- 如果要求“不要动排版”，不要只相信合并后的 DOCX 能打开；要导出 PDF 比较源文件和合并文件页数。
- 需要保留两个文档的页面级布局时，LibreOffice UNO 插入文档有时比 `docxcompose` 更稳。
- 合并后在两个文档交界处检查文本顺序、分页、页眉页脚和页码。
- 有必要时在交界处显式插入分页符。

## 推荐验证命令

```bash
officecli validate thesis.docx
officecli view thesis.docx issues --limit 50
libreoffice --headless --convert-to pdf --outdir /tmp thesis.docx
pdfinfo /tmp/thesis.pdf
pdftotext -layout /tmp/thesis.pdf /tmp/thesis-layout.txt
```

还应把关键页转成图片人工看：

- 封面
- 声明
- 中文摘要
- 英文摘要
- 目录
- 正文首页
- 公式页
- 图表页
- 参考文献首页
- 最后一页
