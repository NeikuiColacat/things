# 可复用 Agent 提示词

## 材料审计

```text
请先审计我的毕设材料，不要写正文。
读取项目代码、已有文档、截图、实验结果和学校模板后，输出：
1. 已有材料清单；
2. 缺失材料清单；
3. 每章可以写什么；
4. 哪些论断缺证据，不能直接写成已完成。
```

## 大纲规划

```text
请根据我的真实项目材料生成本科毕设论文大纲。
要求：
- 采用桂电本科毕设常见结构；
- 每一节写明需要的证据、图、表、代码位置或截图；
- 不要编造实验和功能；
- 不确定的地方标为“待补材料”。
```

## 按章写作

```text
请只写第 X 章。
写作时必须基于我提供的材料和证据表，不要编造数据。
输出包括：
1. 章节正文；
2. 需要插入的图表清单；
3. 需要补充或核验的引用；
4. 本章风险点。
```

## 降低空泛感

```text
请检查这章是否空泛。
把没有真实项目依据的句子列出来，并建议改成：
- 绑定具体模块、代码、截图或实验；
- 或改成限制说明；
- 或删除。
```

## Word 排版检查

```text
请根据桂电模板检查这个 DOCX。
重点检查封面、声明、摘要、目录、页眉页码、标题层级、图表题、参考文献和 PDF 导出效果。
不要只检查 XML，必须导出 PDF 后说明版式问题。
```

## 终稿前审查

```text
请按提交前审查模式检查我的论文。
优先找风险：
- 学术事实或实验数字是否无证据；
- 引用是否缺失；
- 图表是否缺来源；
- 格式是否不符合学校要求；
- 是否有 AI 痕迹、项目无关内容或临时文件路径。
```
